# Code of Conduct

This project follows a simple contributor standard:

- Be respectful and constructive.
- Critique code, design, and evidence rather than people.
- Assume good intent, but keep security and data correctness strict.
- Do not share secrets, private credentials, or proprietary datasets in issues,
  pull requests, examples, or tests.

Maintainers may remove comments, issues, pull requests, or contributors that
violate these expectations.
