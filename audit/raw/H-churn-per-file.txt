Add colony control layer: four-layer multi-agent system for PheroOS

Implement the authorized colony control layer composing four insect-inspired
mechanisms (L0–L3) over PlatformSession:

L0 – Sequential inspection tree (sequential.py): Finite-horizon Bayesian tree in
  joint-probability coordinates. Equivalent to plan_inspection at K=1, with
  Bernstein certificates over declared parameter boxes. Verified bit-exact
  against colony_kernel reference implementation on 6,000+ configs.

L1 – Commitment rules (commitment.py): Cross-inhibition ODE (Seeley/Pais) as
  a deterministic zero-byte ledger filter, plus optimal stopping with recall
  from declared loss distributions. Both integrated into PlatformMixin.commit.

L2 – Response allocation (policies.py): Response threshold heuristic using
  backlog drain time as stimulus. Deterministic step equals pick_threshold;
  Hill response variant for declared, replayable draws.

L3 – Lease evaporation (leases.py): TTL minimization of (1-F(τ))·C_dup + τ·p_fail·c_t
  over positive support, with two-semantics documentation and zero-TTL guard.

Runner integration (colony.py): Bounded sweep composing all layers over a session.
  Tree walk with receipt reuse and recovery, abandoned-reservation handling,
  read-count vs call-cap checks, candidates-before-purchase logic.
