# Removed App Runtime

The old FastAPI/LangGraph/WRDS/multi-agent app runtime was intentionally removed from this protocol-core repository.

Removed surfaces include:

- product API routes
- dashboard/frontend code
- LangGraph reference graph
- model-provider routing
- endpoint catalog
- local server wrappers
- visual regression UI tests
- WRDS and finance-specific workflows
- application-specific capabilities and skills

The repository now optimizes for PheroOS protocol-core cohesion and low external coupling.
