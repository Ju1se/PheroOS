# Swarm Protocol Example

This example is provider-free, network-free, and deterministic. It demonstrates a declared collective decision policy, independent scout reports, recruitment and inhibition signals, pheromone evaporation, a declared safe fallback candidate, output authorization requirements, and swarm trace events.

Run:

```bash
pheroos validate examples/swarm-protocol/capability.json
pheroos conformance examples/swarm-protocol
```
