# Next question — sketch only

When a current result already exists, one inspection is in progress and another
source is missing, does local demand and congestion information redirect an agent
to useful complementary work? No candidate mechanism is implemented in this cleanup.

A future candidate can be one ordinary function combining known evidence,
unmet task demand and the number of workers already assigned. State its failure
mode and remove each input in an ablation. Compare with a strong blackboard/cache
and work-queue baseline under identical permissions, cache, tools and budgets.
Cache reuse belongs to all methods; it is not evidence of a better model policy.

Include complete, missing, stale and conflicting evidence, plus cases with and
without alternative useful work. Avoid round instructions that prescribe the
decision being measured. Count inspection intentions, physical calls, cache hits,
missed necessary checks, correctness, first useful completion time and full cost
separately. Report unchanged actions or null effects without weakening controls.

This is an engineering hypothesis, not a demonstrated biological mechanism or
an algorithmic result. Any future model collection needs separate authorization.
