# Additive interpretation of the one-step probes

The independent audit also records **three actual-only immediate-prefix successes and zero withheld-only successes**. This detail qualifies the phase report: the declared metric remains zero changes with both actions valid; the data do contain a narrower, exploratory action/quality difference when an invalid branch is included.

The three cases are `006-manager_graph:2`, `007-blackboard:2`, and `008-versioned_blackboard:2`, all on the same `code_repair/chunk_count` world. Each actual branch consumed another agent's verified `empty` test receipt and submitted the correct integer ceiling-division patch. With that receipt withheld, the same-seed probe instead requested an unknown test target and was rejected. The previous submitted-candidate history was held fixed for the audit's immediate-prefix scoring.

These are three policy observations on **one previously observed world**, not three independent task replications. Every arm ultimately solved that world, including single and independent. The probes do not establish a final-success advantage, a downstream rollout effect, or a general benefit of collaboration. Under the frozen rule, a pair with an invalid action cannot count as a valid semantic action change. The original metric and outcomes remain unchanged; this posthoc diagnostic is not confirmatory evidence and does not pass G5.

Exact branch records and scores are in `independent_audit.json` under `comparisons`; the original actions, prompts and receipts remain in `trace.jsonl` and `probes.jsonl`. No extra model generation or new hidden feedback was introduced into the pilot.
