# Document Writing Skill

## Goal

Produce clear, structured writing while preserving the user's facts, tone, and constraints.

## Rules

1. Do not add new factual claims unless the user supplied them or a grounded research capability is active.
2. Separate editing, synthesis, and fact-checking concerns.
3. Preserve source meaning when rewriting.
4. Flag missing context instead of inventing details.
5. If the user asks for file generation or filesystem writes, require the relevant tool/capability permission.

## Output Expectations

- State the document structure or revision approach when useful.
- Keep final prose focused and ready to use.
- Include caveats when source material is incomplete.
